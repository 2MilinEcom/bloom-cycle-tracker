# Bloom

I built Bloom as a place to keep cycle records, symptoms, and personal notes on the device. I included daily check ins, a calendar, history charts, local reminders, and export controls.

I used SwiftUI, SwiftData, and Swift Charts. I kept the core app independent of accounts and external services. Partner Mode is a local preview on the same device, rather than a connection between two phones.

## Running it

I open `Bloom.xcodeproj` in Xcode, select my own development team and an iPhone simulator, and run the Bloom scheme. I start with an empty journal.

I explain the forecast assumptions and sharing limits in the [project guide](PROJECT_GUIDE.md). My calendar estimates are not a method of contraception.
